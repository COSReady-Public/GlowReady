# Fonts

Self-hosted so the page makes no third-party font requests.

- `dm-sans.woff2`: DM Sans (weights 400–700, optical size 9–40), © The DM Sans Project Authors
- `schibsted-grotesk.woff2`: Schibsted Grotesk (weights 700–800), © The Schibsted Grotesk Project Authors

Both are licensed under the SIL Open Font License 1.1 (https://openfontlicense.org) and are subset to Latin characters.
